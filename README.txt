# Cognitive Screening Research Prototype

Files: app.py, requirements.txt, README.txt, alzheimers_screening_model.joblib.

Deploy with Streamlit Community Cloud by selecting this GitHub repository, branch main, and main file app.py. Streamlit installs requirements.txt automatically.

The form shows readable dropdowns for Gender, Ethnicity, Education Level, and Yes/No fields. The app converts those selections to the numeric codes expected by the model.

Important: This model was trained on a synthetic dataset and is an academic software demonstration only. It is not a medical device, does not diagnose Alzheimer's disease, and must not be used with real patients or healthcare decisions. Do not enter real patient data.

The numeric measurements and scores should be interpreted using the dataset documentation.
